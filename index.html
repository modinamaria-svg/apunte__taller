Git

Git es un sistema de control de versiones distribuido. En términos simples, es una herramienta que registra todos los cambios realizados en los archivos de un proyecto a lo largo del tiempo, permitiendo recuperar versiones anteriores, comparar estados y trabajar en equipo sin sobreescribir el trabajo de otros.

¿para que sirve?

  • Historial de cambios: Funciona como una "máquina del tiempo" que guarda instantáneas exactas del código.
  • Trabajo colaborativo: Permite que varias personas editen los mismos archivos de manera simultánea sin causar conflictos o pérdida de datos.
  • Ramas de desarrollo (Branches): Permite crear versiones alternas del proyecto para probar nuevas funciones sin alterar el código principal.

GitHub

GitHub es una plataforma en la nube utilizada por desarrolladores para almacenar código fuente y colaborar en proyectos de software. Funciona como una red social para programadores y un sistema de control de versiones, permitiendo a múltiples personas trabajar juntas sin perder o sobreescribir el trabajo de los demás.

¿para que sirve?

  • Control de versiones: Funciona como una máquina del tiempo para tu código.   • Trabajo en equipo (Colaboración): Varios programadores pueden editar el mismo proyecto al mismo tiempo. La plataforma ayuda a fusionar sus cambios de forma lógica y segura.
  • Portafolio profesional: Es la red social de los programadores. Contar con un perfil activo y proyectos subidos sirve como currículum para conseguir trabajo en el sector tecnológico.
